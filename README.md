# Website Pondok Pesantren Nurul Wafa

Situs profil Pondok Pesantren Nurul Wafa, Demung, Besuki, Situbondo — halaman statis tanpa build step.

## Struktur file

- `index.html` — seluruh markup halaman
- `assets/style.css` — seluruh gaya (termasuk mode gelap & aksesibilitas)
- `assets/script.js` — menu, ganti bahasa ID/EN, ukuran huruf, mode gelap, dan formulir PSB bertahap ke WhatsApp
- `assets/*.jpg`, `assets/logo.png` — foto kegiatan & logo pondok

## Menjalankan

Buka `index.html` langsung di browser, atau sajikan folder ini dengan server statis apa pun, misalnya:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000
